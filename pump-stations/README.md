# Информационная система «Управление насосными станциями»

## Назначение
Система предназначена для контроля работы насосных станций (водоснабжение, отопление, пожаротушение): сбора показаний оборудования, выявления аварий и неисправностей, учёта технического обслуживания и ремонта.

## Основные функции
- ведение справочника насосных станций и установленного оборудования (насосы, датчики, шкафы управления);
- приём и хранение показаний: давление, расход, состояние насосов;
- сравнение показаний с допустимыми значениями и формирование аварийных сообщений;
- выявление неисправных насосов и формирование предупреждений;
- создание заявок на ремонт и учёт технического обслуживания;
- журнал событий и отчёты по работе станций.

## Состав папки
- `README.md` — назначение системы и перечень функций;
- `requirements.md` — пользователи, функциональные и нефункциональные требования;
- `modules.md` — модули системы и их взаимодействие.
