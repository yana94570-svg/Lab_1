# Информационная система «Индивидуальный план преподавателя»

## Назначение системы

Информационная система предназначена для автоматизации формирования, хранения и контроля индивидуальных планов преподавателей.

## Основные функции

- Создание и редактирование индивидуального плана преподавателя.
- Добавление учебных, методических и научных мероприятий.
- Указание сроков выполнения запланированных работ.
- Контроль выполнения мероприятий.
- Формирование отчётов о выполненной работе.

## Основные данные

- Преподаватели.
- Учебные годы.
- Индивидуальные планы.
- Запланированные мероприятия.
- Сроки и статусы выполнения.
- Отчёты.

## Участник команды

Разработка проекта информационной системы «Индивидуальный план преподавателя».
