# Модули информационной системы «Индивидуальный план преподавателя»

## 1. Модуль управления преподавателями

Предназначен для хранения сведений о преподавателях: фамилии, имени, должности, кафедре и контактных данных.

## 2. Модуль управления индивидуальными планами

Обеспечивает создание, просмотр и редактирование индивидуальных планов на определённый учебный год.

## 3. Модуль учёта мероприятий

Позволяет добавлять учебные, методические, научные и организационные мероприятия, указывать сроки выполнения и планируемые результаты.

## 4. Модуль контроля выполнения

Предназначен для отслеживания состояния мероприятий. Каждому мероприятию можно присвоить статус: «Запланировано», «Выполняется» или «Выполнено».

## 5. Модуль формирования отчётов

Формирует отчёты о запланированных и выполненных мероприятиях за выбранный период.

## 6. Модуль управления доступом

Разграничивает права пользователей. Преподаватель работает со своим планом, руководитель контролирует выполнение, администратор управляет учётными записями.

## Взаимодействие модулей

Модуль управления преподавателями предоставляет сведения о пользователях. Модуль индивидуальных планов связывает преподавателей с мероприятиями. Модуль контроля выполнения обновляет статусы мероприятий, а модуль отчётов использует сохранённые данные для формирования итоговой информации.
