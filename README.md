# Книжный интернет-магазин с подсистемой персонализированных рекомендаций

## Описание проекта

Книжный интернет-магазин — это информационная система, предназначенная для поиска, просмотра и покупки книг через интернет.

Особенностью системы является подсистема персонализированных рекомендаций, которая помогает пользователям находить книги с учётом их интересов, предпочтительных жанров, истории просмотров и покупок.

## Основные функции

* Просмотр каталога книг.
* Поиск книг по названию и автору.
* Фильтрация книг по жанрам.
* Просмотр информации о книгах.
* Добавление книг в корзину.
* Оформление заказов.
* Просмотр истории заказов.
* Формирование персонализированных рекомендаций.
* Подбор книг на основе предпочтений пользователя.

## Цель проекта

Разработать информационную систему для продажи книг через интернет, которая упрощает поиск интересующих произведений и повышает удобство выбора благодаря персонализированным рекомендациям.
